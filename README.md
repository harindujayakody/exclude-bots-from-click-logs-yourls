# Exclude Bots from Click Logs for YOURLS

A plugin for [YOURLS](https://yourls.org/) (Your Own URL Shortener) that prevents clicks generated by automated web spiders, social media link preview generators, and AI web crawlers from polluting your click analytics.

## How It Works

YOURLS provides the `shunt_log_redirect` filter hook which intercepts `yourls_log_redirect()`. When a bot user agent requests a short URL:
- Logging is bypassed (preventing inflated analytics counters).
- The HTTP redirect itself proceeds completely unimpeded (social media link unfurls and previews continue to work seamlessly).

## Detected Bots & Crawlers

Includes search engines, social media unfurlers, and modern AI crawlers:
- **Search Engines:** Googlebot, Bingbot, YandexBot, DuckDuckBot, Baiduspider, Applebot.
- **Social & Chat Previews:** Facebook External Hit, Twitterbot, LinkedInBot, Slackbot, Discordbot, WhatsApp, Redditbot, Telegram.
- **AI & LLM Crawlers:** GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot, Bytespider, CCBot, Meta-ExternalAgent, Amazonbot.

## Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/harindujayakody/exclude-bots-from-click-logs-yourls.git
   ```
2. Move the directory to your YOURLS plugins folder:
   ```
   user/plugins/exclude-bots-from-click-logs-yourls/
   ```
3. Activate the plugin in the YOURLS Admin area under **Manage Plugins**.

## Testing

Run the included PHP test script:
